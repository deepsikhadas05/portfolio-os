# Overview

Completed a 12-month internship as an Infrastructure Engineer Intern within the Fleet IT Infrastructure team at A.P. Moller - Maersk.

Worked on enterprise-scale infrastructure supporting maritime vessel environments, with responsibilities spanning automation, systems administration, software deployment, virtual machine provisioning, and infrastructure support.

The work primarily focused on improving operational efficiency through automation while maintaining reliability in large-scale production environments.

---

# Responsibilities

Major responsibilities included:

- Automating infrastructure-related tasks using PowerShell and Python.
- Deploying software and security agents across vessel environments.
- Provisioning and configuring virtual machines.
- Supporting Windows Server infrastructure.
- Assisting with Linux-based systems.
- Managing enterprise software deployments.
- Troubleshooting infrastructure and networking issues.
- Handling ServiceNow support tickets.
- Developing and Maintaining offline patch deployment framework.
- Improving operational workflows through automation.

---

# Major Contributions

## Offline Patch Deployment Framework

Contributed to an offline WSUS-based patch deployment framework designed for maritime vessels operating with limited or intermittent internet connectivity.

Responsibilities included:

- Packaging Windows updates.
- Managing update approvals.
- Supporting metadata synchronization.
- Improving deployment automation.
- Assisting phased rollout processes.

---

## Security Agent Deployment

Developed automation scripts to simplify deployment of security agents across thousands of systems operating in isolated maritime environments.

Goals included:

- Reducing manual effort.
- Increasing deployment consistency.
- Improving operational efficiency.

---

## Virtual Machine Provisioning

Provisioned and configured Cyber Security Gateway virtual machines across fleet infrastructure.

Activities included:

- VM deployment
- Configuration
- Validation
- Infrastructure readiness

---

## Infrastructure Dashboard

Developed a Streamlit dashboard for monitoring patch deployment status.

The dashboard aggregated infrastructure data and presented deployment status in an accessible interface for operational monitoring.
